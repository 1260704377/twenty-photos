# 20张 v0.1.0

每天只整理 20 张照片。所有照片和整理记录只保存在本机。

## 下载与使用

下载 Mac Apple Silicon 压缩包，解压后打开「20张.app」，选择本地照片文件夹即可开始。运行已打包应用不需要 Node.js。

当前提供 Apple Silicon Mac 版本。应用未做 Apple 开发者签名或公证。Windows 的源码、启动脚本和构建配置已提供，尚未进行 Windows 真机验证。

## 本次功能

- 本地照片文件夹扫描，每天最多整理 20 张，不足时按剩余数量。
- 单张大图浏览，保留、收藏、待删除和稍后决定，以及键盘快捷键。
- 撤销上一步、结果回看与修改、草稿自动保存和重启续接。
- 最终确认后安全移动至「20张整理/收藏」或「20张整理/待删除」，可恢复原位。
- 本地累计统计、连续天数、EXIF「过去的今天」优先。
- 按需预览、Mac HEIC 解码兜底和无法读取图片的错误状态。

## 文件安全

没有永久删除功能。最终确认前不改动原照片；移动时不覆盖不同内容的文件，并记录恢复信息及校验文件内容。待清理空间不代表已经释放的磁盘空间。

## 验证

15 项核心测试通过；真实 Electron 桌面完整流程通过；打包后启动、JPEG/HEIC 解码和小窗口布局验证通过。测试使用自动生成的独立样本，不使用个人照片。
